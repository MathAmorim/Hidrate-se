# 💧 Hidrate-se

O **Hidrate-se** é um aplicativo Android focado no monitoramento e incentivo ao consumo diário de água, utilizando elementos de gamificação para criar hábitos saudáveis.

## ✨ Principais Funções
* **Registro de Consumo:** Controle rápido da ingestão de água.
* **Metas Diárias:** Configuração de objetivos personalizados.
* **Conquistas:** Sistema de troféus para premiar a consistência.
* **Lembretes:** Notificações configuráveis para manter o foco.
